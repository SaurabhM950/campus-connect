# Campus Connect

Build a responsive College Club Event Management Website.

Student/User Side

Create the following pages and features:

Home Page

Club introduction

Upcoming events

Featured event

Events Page

List all events

Event cards containing:

Event name

Date & time

Venue

Description

Registration button

Search events by name

Filter events by category

Event Registration
Create a registration form with:

Name

Email

College/Year

Phone number

Submit Registration button

The complete website should be fully responsive.

Admin Side

Create a simple Admin Dashboard where admins can:

Add an event

Edit an event

Delete an event

View registered students

Search registrations

Filter registrations

Build the UI cleanly and make all the above features functional.
